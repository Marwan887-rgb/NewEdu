إصلاح جدول الطلاب

إضافة عمود chat_id إلى جدول students

1 افتح Supabase Dashboard

🔗 افتح Dashboard

2 اذهب إلى Table Editor

اختر جدول students

3 أضف عمود جديد

• اضغط على "+ New Column"

• الاسم: chat_id

• النوع: text أو varchar

• اجعله nullable (يمكن أن يكون فارغ)

• احفظ التغييرات

⚡ أو استخدم SQL مباشرة:

ALTER TABLE students
ADD COLUMN IF NOT EXISTS chat_id TEXT;

انسخ هذا الكود وشغله في SQL Editor

✅ التحقق

بعد إضافة العمود، تحقق بهذا الكود:

SELECT * FROM students LIMIT 1;

يجب أن ترى عمود chat_id في النتائج!
