   • صفحة المعلم

سيبقى كما هو:
✓ بيانات الطلاب (students)
✓ ملفات Storage

════════════════════════════════════════════════════════════
🚀 خطوات التنفيذ
════════════════════════════════════════════════════════════

الخطوة 1: النسخ الاحتياطي
─────────────────────────
Supabase Dashboard
→ Database
→ Backups
→ Create New Backup
→ اكتب اسم: "قبل تحديث الأرقام - 2025/10/28"
→ انتظر حتى تكتمل

الخطوة 2: فتح الملف
──────────────────────
افتح: SAFE_RESET_LESSON_IDS_V2.sql
اقرأ المحتوى بسرعة للتأكد

الخطوة 3: التنفيذ
───────────────────
Supabase → SQL Editor
→ انسخ محتوى الملف كاملاً
→ الصق في SQL Editor
→ ⏸️ توقف! راجع مرة أخيرة
→ اضغط Run

الخطوة 4: الانتظار
──────────────────
• انتظر (1-2 دقيقة)
• لا تغلق الصفحة
• راقب الرسائل

الخطوة 5: التحقق من النتيجة
───────────────────────────
يجب أن ترى:
✅ جداول بالنتائج
✅ "التحديث اكتمل بنجاح!"
✅ 21 درس
✅ توزيع صحيح

🧪 الاختبار بعد التنفيذ
════════════════════════════════════════════════════════════

في Supabase:
───────────
SELECT COUNT(*) FROM lessons;
-- المتوقع: 21

SELECT id, title, type FROM lessons ORDER BY id;
-- المتوقع: أرقام منظمة

SELECT COUNT(*) FROM progress;
-- المتوقع: نفس العدد أو أقل

SELECT COUNT(*) FROM project_submissions;
-- المتوقع: 0

في الموقع (كطالب):
────────────────────
□ افتح صفحة الدروس
□ 3 وحدات تظهر؟
□ كل وحدة 7 عناصر؟
□ افتح درس → يعمل؟
□ افتح نشاط → يعمل؟
□ افتح مشروع → يعمل؟

في لوحة المعلم:
────────────────
□ الدروس تظهر صحيح؟
□ تقدم الطلاب يظهر؟
□ الإحصائيات صحيحة؟

════════════════════════════════════════════════════════════
🔄 في حالة المشاكل
════════════════════════════════════════════════════════════

إذا ظهر خطأ:
─────────────
1. لا تذعر!
2. Transaction يلغي التغييرات تلقائياً
3. قاعدة البيانات آمنة

إذا نجح التنفيذ لكن النتيجة خاطئة:
───────────────────────────────────────
1. Supabase → Database → Backups
2. اختر النسخة الاحتياطية
3. اضغط Restore
4. راجع المشكلة
5. أعد المحاولة

إذا اكتشفت مشكلة بعد أيام:
────────────────────────────────
• للأسف النسخة الاحتياطية قد تُحذف
• لذلك: اختبر جيداً مباشرة بعد التنفيذ!

════════════════════════════════════════════════════════════
✅ النتيجة النهائية
════════════════════════════════════════════════════════════

بعد التنفيذ الناجح، ستحصل على:

✓ 21 درس بأرقام منظمة
✓ 9 دروس عادية (1-9)
✓ 3 مشاريع (20-22)
✓ 3 أنشطة (30-32)
✓ 3 مراجعات (40-42)
✓ 3 اختبارات وحدة (50-52)
✓ progress محدث
✓ activities محدث
✓ unit_exams محدث
✓ قاعدة بيانات نظيفة
✓ لا أخطاء

════════════════════════════════════════════════════════════
💡 نصائح مهمة
════════════════════════════════════════════════════════════

1. نفّذ في وقت قليل النشاط
2. أخبر الطلاب مسبقاً
3. احفظ نسخة من الملفات المرفوعة (Storage)
4. اختبر فوراً بعد التنفيذ
5. لا تؤجل الاختبار!
