# حل بسيط - إزالة Flip Card

## المشكلة:
- البطاقة القابلة للقلب (Flip Card) معقدة وتسبب مشاكل
- الوحدات لا تظهر بشكل صحيح

## الحل البسيط:
إزالة نظام Flip Card تماماً وجعل التصميم بسيط:

### 1. الفترات في الأعلى (ظاهرة دائماً)
### 2. زر "عرض الدروس" يعرض الوحدات تحت الفترات
### 3. الوحدات تظهر عمودياً (واحدة تحت الأخرى)
### 4. عند الضغط على وحدة، تظهر الدروس

---

## التعديلات المطلوبة في `index.html`:

### ١. حذف CSS الخاص بـ Flip Card

ابحث عن هذا القسم واحذفه:
```css
/* Flip Card CSS */
.flip-card-container { ... }
.flip-card-inner { ... }
.flip-card-front { ... }
.flip-card-back { ... }
```

### ٢. تبديل HTML

**احذف:**
```html
<div class="flip-card-container" id="main-flip-card">
  <div class="flip-card-inner">
    <div class="flip-card-front">
      <!-- الفترات -->
    </div>
    <div class="flip-card-back">
      <!-- الوحدات -->
    </div>
  </div>
</div>
```

**استبدله بـ:**
```html
<div class="w-full">
  <!-- الفترات -->
  <div id="terms-cards-view" class="flex flex-col sm:flex-row flex-wrap gap-2 p-2 mb-4">
    <!-- بطاقات الـ 5 هنا كما هي -->
  </div>
  
  <!-- الوحدات (مخفية افتراضياً) -->
  <div id="units-section" class="hidden">
    <button onclick="hideUnits()" class="mb-3 px-4 py-2 bg-blue-500 text-white rounded-xl">
      ← العودة
    </button>
    <div id="units-list-vertical" class="flex flex-col gap-3"></div>
  </div>
</div>
```

### ٣. تعديل JavaScript

**احذف:**
```javascript
function toggleFlipCard() { ... }
function renderUnitsInFlip() { ... }
```

**أضف:**
```javascript
// عرض الوحدات
function showUnitsSimple() {
  document.getElementById('terms-cards-view').classList.add('hidden');
  document.getElementById('units-section').classList.remove('hidden');
  loadUnitsVertical();
}

// إخفاء الوحدات
function hideUnits() {
  document.getElementById('terms-cards-view').classList.remove('hidden');
  document.getElementById('units-section').classList.add('hidden');
}

// تحميل الوحدات عمودياً
function loadUnitsVertical() {
  const grouped = {};
  lessonsData.forEach(lesson => {
    const unit = lesson.unit || 'بدون وحدة';
    if (!grouped[unit]) grouped[unit] = [];
    grouped[unit].push(lesson);
  });
  
  let html = '';
  Object.keys(grouped).forEach(unitName => {
    const lessons = grouped[unitName];
    const count = lessons.length;
    
    html += `
      <div class="unit-card-wrapper" onclick="showUnitLessons('${unitName}')">
        <div class="unit-card-header">
          <div class="unit-icon-box">
            <svg class="w-5 h-5 text-white" fill="none" stroke="currentColor" viewBox="0 0 24 24">
              <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M9 12h6m-6 4h6m2 5H7a2 2 0 01-2-2V5a2 2 0 012-2h5.586a1 1 0 01.707.293l5.414 5.414a1 1 0 01.293.707V19a2 2 0 01-2 2z" />
            </svg>
          </div>
          <h3 class="unit-title">${unitName}</h3>
        </div>
        <p class="text-center text-purple-700 font-bold">${count} درس</p>
        <button class="unit-view-btn">عرض المحتوى →</button>
      </div>
    `;
  });
  
  document.getElementById('units-list-vertical').innerHTML = html;
}
```

### ٤. تعديل زر "عرض الدروس"

غيّر `onclick` من `toggleFlipCard()` إلى `showUnitsSimple()`
