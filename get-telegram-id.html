ربط حساب التليجرام

احصل على Chat ID للطالب

1 إنشاء بوت تليجرام

راسل @BotFather وأنشئ بوت جديد

/newbot

2 احصل على Bot Token

بعد إنشاء البوت، ستحصل على Token مثل:

123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ

3 إنشاء رابط للطالب

الرابط يكون بهذا الشكل:

https://t.me/YourBotUsername?start=0500000000

استبدل YourBotUsername برقم الجوال

4 حفظ Chat ID

عندما يضغط الطالب على الرابط ويرسل /start:

  • ✅ البوت يستقبل رسالة بـ chat_id
  • ✅ احفظ chat_id في قاعدة البيانات
  • ✅ الآن يمكنك إرسال إشعارات للطالب
