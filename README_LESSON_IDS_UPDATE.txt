⚡ البدء السريع (Quick Start)
════════════════════════════════════════════════════════════

1. 💾 عمل نسخة احتياطية في Supabase

2. 📥 تنفيذ الملفات بالترتيب:
   ① ADD_MISSING_LESSONS.sql
   ② UPDATE_LESSON_IDS_COMPLETE.sql

3. ✅ التحقق:
   SELECT COUNT(*) FROM lessons;
   -- يجب أن يظهر: 21

4. 🧪 الاختبار:
   • صفحة الطالب
   • صفحة المعلم

════════════════════════════════════════════════════════════
📊 النتيجة المتوقعة
════════════════════════════════════════════════════════════

بعد التنفيذ، ستحصل على:

✓ 21 درس بأرقام منظمة
✓ بدون تعارضات
✓ جميع الوظائف تعمل
✓ الكود لا يحتاج تعديل

التوزيع:
• 9 دروس عادية (01-09)
• 3 مشاريع (20-22)
• 3 أنشطة (30-32)
• 3 مراجعات (40-42)
• 3 اختبارات وحدة (50-52)

════════════════════════════════════════════════════════════
💡 ملاحظات مهمة
════════════════════════════════════════════════════════════

1. الكود البرمجي لا يحتاج تعديل
   • يستخدم lesson.id ديناميكياً
   • سيعمل تلقائياً مع الأرقام الجديدة

2. النسخ الاحتياطي إجباري
   • قبل التنفيذ
   • في حالة وجود مشاكل

3. Transaction Safety
   • كل التغييرات في transaction واحد
   • إذا حدث خطأ، يتم الإلغاء تلقائياً

4. Foreign Keys
   • يتم تعطيلها مؤقتاً
   • ثم إعادة تفعيلها
